# ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ТЗ)

**Наименование проекта:** Разработка интерактивной панели управления свойствами объектов XDATA для AutoCAD их добавление для примитивов и удаление

**Язык программирования:** C# (.NET Framework / .NET)

**Технология UI:** WPF (Windows Presentation Foundation)

**Целевая платформа:** AutoCAD (AutoCAD .NET API)

---

## 1. ОБЩЕЕ ОПИСАНИЕ И АРХИТЕКТУРА

Плагин представляет собой запечатываемую панель (**PaletteSet** в AutoCAD), содержащую формализованный UI на WPF. Панель предназначена для отображения, группового редактирования и синхронизации расширенных данных (XData) выделенных графических примитивов (блоки устройств (динамические блоки), кабели (полилиния) и суперлиния(отрезок)  ).

### Архитектурный паттерн:

* **MVVM (Model-View-ViewModel):** Разделение логики AutoCAD API, обработки данных и графического интерфейса.
* **Связывание данных (DataBinding):** Все изменения полей UI через ViewModel транслируются в транзакции AutoCAD (`TransactionManager`).

### ЭТАП 3. Обработчик событий выбора и парсер XData (Visual Tree String)

#### Логика работы с XData примитива:

1. Подписка на событие AutoCAD `SelectionChanged` (изменение набора выделения).
2. Если ничего не выбрано — панель переходит в состояние `Disabled` (неактивна).
3. При выборе одного или нескольких примитивов выполняется считывание зарегистрированного приложения `RegApp` (например, `ESMT_LEP_v1.0` или `BobrovXDATA`):


* Считываются все записи `XData` и/или связанный `XRecord` из `ExtensionDictionary`.


* Формируется объектная модель **Visual Tree String** — структурированный граф/дерево всех параметров и материалов, привязанных к объекту.



---

### ЭТАП 4. Логика группового редактирования и обработки значения "Разное"

#### Требования к мульти-выбору (Выделено N примитивов):

1. **Сравнение свойств:**
При выделении нескольких объектов программа выполняет попарное сравнение всех полей и элементов списка XData.
2. **Логика вывода значения "Разное":**
* Если у **всех** выделенных примитивов значение конкретного XData-поля (например, `Название` или `Марка` материала) полностью совпадает — отображается это значение.


* Если **хотя бы у одного** примитива значение отличается (или данный материал присутствует не у всех примитивов) — в соответствующем поле UI отображается плейсхолдер **`Разное`** (курсивом или серой подсвечкой).


3. **Групповое редактирование:**
* Если пользователь изменяет поле со значением `Разное` (или любое другое) и подтверждает ввод (нажатие `Enter` / потеря фокуса):
* Применение транзакции ко **всем выбранным примитивам**.
* Новое значение записывается в `XData` / `XRecord` каждого выделенного примитива.




* **Материалы (Добавление/Удаление в группе):**
* При нажатии `+ Добавить` новый материал добавляется в XData **всех** выделенных примитивов.
* При нажатии `X` (Удалить) данная марка материала удаляется из XData **всех** выделенных примитивов.

### ЭТАП 5. Редактирование и запись XData в базу DWG

#### Задачи:

1. Реализация сервиса запись данных `XDataWriter`:
* Открытие транзакции AutoCAD (`using (Transaction tr = db.TransactionManager.StartTransaction())`).
* Перевод ViewModel обратно в структуры `ResultBuffer` (для XData) или в XML-строку (для `XRecord` в `ExtensionDictionary`).


* Обновление данных объектов с вызовом `tr.Commit()`.


2. Поддержка отмены операций (`Undo / Redo`):
* Все операции редактирования через панель должны корректно записываться в стек отмены AutoCAD (при нажатии `Ctrl+Z` изменения в XData должны откатываться).





3. **Корректность обработки "Разное":** Проверка, что редактирование одного совпавшего поля не затирает уникальные разнящиеся данные других полей.

## 3. ОПИСАНИЕ СТРУКТУРЫ ДАННЫХ (Visual Tree String XData)

Для реализации вывода материалов в виде дерева/списка (Visual Tree String) модель данных материала должна иметь следующий вид (C# DTO):

```csharp
public class MaterialItemViewModel : INotifyingPropertyChanged
{
    public string Category { get; set; } // Например: "Железобетонные элементы"
    public string Name { get; set; }     // Марка: "СВ110-5"
    public string Count { get; set; }    // Кол-во: "1" (или "Разное")
    public bool? IsInSpec { get; set; }  // Флаг в спецификацию (true/false/null для "Разное")
    public string Comment { get; set; }  // Примечание
    
    public bool IsMixedValue { get; set; } // Флаг, указывающий на разнородность данных при групповом выборе
}

```
